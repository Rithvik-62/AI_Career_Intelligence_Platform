3. WHY DID WE BUILD IT? (THE PROBLEM)
================================================================================

PROBLEM IN TODAY'S WORLD:

  Every year, millions of engineering students and fresh graduates face a
  massive challenge when they enter the job market:

  PROBLEM 1: Students don't know which career role suits them best.
  ---------------------------------------------------------------
  A student who has learned Python, SQL, and Machine Learning may not know
  whether they should apply for "Data Scientist," "ML Engineer," or
  "Data Analyst." They waste months applying for the wrong roles.

  PROBLEM 2: Resumes get rejected by ATS systems automatically.
  ------------------------------------------------------------
  Most companies use ATS (Applicant Tracking Systems) — automated software
  that scans resumes before a human ever sees them. If your resume doesn't
  have the right keywords, it gets rejected automatically. 75% of resumes
  are rejected by ATS before reaching a recruiter.

  PROBLEM 3: Students don't know what skills they are missing.
  -----------------------------------------------------------
  Even if a student knows they want to be a Data Scientist, they don't know
  exactly which skills they need to learn. There is no personalized guidance.

  PROBLEM 4: Career counselors are expensive and unavailable.
  ---------------------------------------------------------
  Professional career counseling costs Rs. 5,000 to Rs. 50,000+ per session.
  Most college students cannot afford this.

  PROBLEM 5: Resume writing services are manual and slow.
  -----------------------------------------------------
  Getting resume feedback from professionals takes days or weeks.

4. WHAT PROBLEMS DOES IT SOLVE?
================================================================================

OUR SOLUTION — HOW WE SOLVE EACH PROBLEM:

  SOLUTION 1: AUTOMATIC CAREER ROLE PREDICTION
  -----------------------------------------------
  The system analyzes your resume text using a trained Machine Learning model

9. HOW THE PROJECT WORKS — STEP BY STEP
================================================================================

STEP 1: USER OPENS THE APPLICATION
  - Open browser and go to the application URL
  - The Home page loads with the AI Career Intelligence Platform dashboard

STEP 2: UPLOAD RESUME PDF
  - Click the "Upload" button on the Home page
  - Select your resume PDF file from your computer
  - File size limit: 10MB maximum

STEP 3: CLICK "INITIALIZE AI ANALYSIS SEQUENCE"
  - The system begins a multi-stage processing pipeline
  - A progress bar shows the status of each stage

STAGE A: RESUME PARSING (0.3 seconds)
  - pdfplumber opens the PDF and extracts all text
  - ResumeParser processes the text through 15+ extraction algorithms
  - Outputs a structured data dictionary with all candidate information

STAGE B: ML CAREER PREDICTION (0.1 seconds)
  - The extracted text is cleaned and lowercased
  - TF-IDF Vectorizer converts text into numerical feature vectors
  - Decision Tree model processes the feature vector
  - Outputs TOP 5 career role predictions with confidence percentages

STAGE C: RESUME SCORING (0.2 seconds)
  - ResumeScorer analyzes the parsed data
  - Calculates score across 5 categories (Skills, Experience, Projects, etc.)
  - Computes ATS compatibility and career readiness
  - Outputs multi-dimensional score dictionary

STAGE D: SKILL GAP ANALYSIS (0.1 seconds)
  - SkillGapAnalyzer compares candidate's skills against role requirements
  - Queries the internal CAREER_DATABASE for the predicted role
  - Identifies matched skills, missing skills, priority order
  - Estimates learning hours per missing skill

STAGE E: AI INSIGHTS GENERATION (0.1 seconds)
  - InsightEngine processes all data from previous stages
  - Generates executive insight summary (top strength, main weakness, etc.)

STEP 4: EXPLORE RESULTS ACROSS 18 PAGES
  - Home Overview — Summary and navigation
  - Resume Deep Extraction — Full parsed profile view
  - ML Career Prediction — Top 5 roles with confidence
  - ATS Resume Score — Detailed scoring breakdown

HOW EACH MAJOR MODULE WORKS:
---

MODULE 1: utils/parser.py — THE RESUME EXTRACTION ENGINE
  - _extract_text_from_pdf():
      Opens the PDF using pdfplumber
      Reads every page and combines all text
      Cleans invisible Unicode characters and formatting artifacts
      Returns one long string of raw text

  - _extract_name():
      Reads only the TOP 15 lines of the resume (where names always appear)
      Strips away emails, phone numbers, URLs, degree titles, section headings
      Scores remaining word groups by length (2-4 words = likely a name)
      Returns the most likely candidate name

  - _extract_email():
      Uses regex pattern: \b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b
      Finds the first valid email address in the text

  - _extract_phone():
      Uses regex to find phone patterns like +91-9876543210, (555) 234-5678
      Validates digit count (must have at least 7 digits)
      Ignores year ranges (2020-2024 would be incorrectly matched)

  - _extract_links():
      Searches for linkedin.com/in/ pattern → LinkedIn URL
      Searches for github.com/ pattern → GitHub URL
      Searches for other domain URLs → Portfolio URL

  - _extract_location():
      Looks for "City, STATE" or "City, Country" patterns in top 25 lines
      Validates against a dictionary of US states and world countries
      Strips false matches (e.g., "Technology Atlanta, GA" → "Atlanta, GA")

  - _extract_skills():
      Has a dictionary of 100+ technical skills
      Uses regex with word boundaries to avoid false matches
      Maps variations to normalized names (e.g., "node.js" → "Node.js")
      Returns sorted, deduplicated skill list

  - _extract_sections():
      Reads through all lines looking for section headers
      Headers like "EDUCATION", "EXPERIENCE", "PROJECTS" trigger section change
      Groups lines under each section
      Returns a dictionary of raw text blocks for each section

  - _parse_education():
      Splits education section line by line
      Detects degree keywords (Bachelor, BCA, PUC, SSLC, 10th, M.S.)
      Creates a separate education card for each degree found

  - _parse_projects():
      Identifies short title lines (≤8 words, no bullet, no period)
      Groups description bullets under each project title
      Extracts technologies from project descriptions

  - _parse_certifications():
      Groups certification course titles and bullet descriptions
      Creates one cohesive card per course/certification

MODULE 2: utils/predictor.py — THE ML PREDICTION ENGINE
  - Loads 3 pre-trained model files:
      career_model.pkl    → The trained classifier
      vectorizer.pkl      → TF-IDF feature transformer
      label_encoder.pkl   → Converts number labels to role names

  - predict(pdf_file_path):
      1. Calls parser.parse() to get candidate data
      2. Calls _extract_text_from_pdf() to get raw text
      3. Calls clean_text() from cleaner.py to normalize text
      4. Calls vectorizer.transform() to convert text to numbers
      5. Calls model.predict_proba() to get probability for each career role
      6. Returns TOP 5 roles sorted by confidence %
      7. Returns feature contributions (which words influenced the prediction)

MODULE 3: utils/scoring.py — THE ATS SCORING ENGINE
  - score_resume(parsed_data):
      Skills Score: counts skills found (up to 30 points)
      Experience Score: counts job entries found (up to 20 points)
      Projects Score: counts project entries found (up to 20 points)
      Education Score: checks degrees found (up to 15 points)
      Certifications Score: checks certs found (up to 15 points)
      ATS Score: checks for required sections, keyword density
      Career Readiness: weighted combination of all scores
      Outputs rating tier based on overall score range

MODULE 4: utils/skill_gap.py — THE SKILL GAP ENGINE
  - Has a CAREER_DATABASE dictionary mapping each role to required skills
  - analyze(parsed_data, target_role):
      1. Gets required skills for the target role from CAREER_DATABASE
      2. Compares against candidate's extracted skills
      3. Calculates Coverage % = matched / total required × 100
      4. Ranks missing skills by importance (Critical, High, Medium)
      5. Estimates learning hours for each missing skill
      6. Returns structured gap report

MODULE 5: utils/gemini_ai.py — THE GEMINI AI INTEGRATION
  - Connects to Google Gemini 3.6 Flash API using API key
  - generate_cover_letter(parsed_data, target_role):
      Builds a detailed prompt with candidate info + role requirements
      Sends to Gemini API and returns formatted cover letter
  - chat_with_aria(message, context):
      Maintains conversation history
      Sends user message + resume context to Gemini
      Returns AI response as Aria (the career chatbot)

MODULE 6: app/streamlit_app.py — THE MAIN ENTRY POINT
  - Configures the Streamlit multipage navigation
  - Sets up the page title, icon, and layout
  - Defines the sidebar navigation menu
  - Routes to individual page files

MODULE 7: app/ui_components.py — THE UI DESIGN SYSTEM
  - inject_global_css(): Injects Aurora Dark Theme CSS
      Background: #0F172A (deep dark blue)
      Primary: #2563EB (vibrant blue)
      Accent: #06B6D4 (cyan)
      Success: #22C55E (green)
      Uses glassmorphism (frosted glass effect) for cards
  - hero_banner(): Creates the animated banner on the home page
  - premium_card(): Creates beautiful dark-themed information cards
  - render_aria_sidebar_chatbot(): Renders the AI chatbot in the sidebar

12. MACHINE LEARNING EXPLANATION (SIMPLE)
================================================================================

WHAT IS TF-IDF?
  TF-IDF stands for Term Frequency - Inverse Document Frequency.
  It is a way to convert text (words) into numbers that a computer can understand.

  Example: If your resume has the word "python" 5 times out of 200 total words,
  and "python" is rare across all resumes, it gets a HIGH score.
  If "the" appears 20 times, it gets a LOW score (too common to be useful).

WHAT IS DECISION TREE?
  A Decision Tree is a flowchart-style algorithm.
  
  Example simplified:
    Does resume contain "docker" AND "kubernetes"?
      YES → Likely "Cloud Engineer" or "DevOps Engineer"
      NO  → Does it contain "pandas" AND "scikit-learn"?
              YES → Likely "Data Scientist"
              NO  → Does it contain "react" AND "javascript"?
                      YES → Likely "Web Developer"

HOW WE TRAINED THE MODEL:
  1. We collected a dataset of thousands of real resumes labeled with career roles
  2. Each resume was cleaned and converted to TF-IDF feature vectors
  3. The Decision Tree algorithm was trained on these feature vectors
  4. The trained model was saved as career_model.pkl
  5. When you upload YOUR resume, your text is converted the SAME way
     and the model predicts which career category your text pattern matches

MODEL ACCURACY:
  Our model achieves approximately 80-95% accuracy on the training dataset.
  The accuracy varies by career role — highly technical roles like
  "Cloud Engineer" (keywords like docker, kubernetes, terraform) are more
  accurately predicted than broad roles like "Software Developer."

20. WHAT THE EXAMINER WILL ASK (FAQs)
================================================================================

Q1: What is the main purpose of this project?
A: This is an AI-powered career analytics platform that automatically analyzes
   resumes, predicts career roles using Machine Learning, scores ATS readiness,
   identifies skill gaps, and generates personalized learning roadmaps.

Q2: What Machine Learning algorithm did you use?
A: We used a Decision Tree Classifier with TF-IDF vectorization from Scikit-Learn.
   The model was trained on a labeled dataset of resumes mapped to career roles.
   It achieves approximately 85-90% accuracy on cross-validation.

Q3: What is TF-IDF?
A: Term Frequency-Inverse Document Frequency. It converts text into numerical
   vectors where words that appear frequently in a specific resume but rarely
   across all resumes get higher weights. This helps the model identify which
   words are most relevant for career classification.

Q4: How does the resume parser work?
A: We use pdfplumber to extract raw text from PDFs, then apply regular expressions
   (regex) and NLP heuristics to extract specific fields like name, email, phone,
   LinkedIn, GitHub, skills, education, experience, projects, and certifications.

Q5: What is ATS scoring?
A: ATS stands for Applicant Tracking System. Companies use ATS software to
   automatically filter resumes before human review. Our scoring system calculates
   how well a resume would perform in ATS scanning based on keyword presence,
   section completeness, and structural quality.

Q6: How is the Gemini AI used?
A: Google Gemini 3.6 Flash is used for generating AI Cover Letters, LinkedIn
   Summaries, and powering the Aria chatbot. We send the candidate's parsed
   resume data as context along with specific task prompts to the Gemini API.

Q7: What is the difference between this and a normal resume checker?
A: Normal resume checkers only give keyword feedback. Our platform uses actual
   Machine Learning classification to predict optimal career roles, performs
   multi-dimensional scoring across 5 categories, generates personalized
   learning roadmaps, and integrates Gemini AI for content generation —
   making it a complete career intelligence system, not just a checker.

Q8: Is the API key secure?
A: Yes. The API key is stored in .streamlit/secrets.toml which is excluded from
   GitHub via .gitignore. On Streamlit Cloud, it is stored in their encrypted
   Secrets Dashboard, never exposed in source code.

Q9: What datasets did you use?
A: We used industry-standard resume datasets for ML model training. The dataset
   contains thousands of real resume texts labeled with career categories.
   The trained model is serialized to career_model.pkl and loaded at runtime.

Q10: How is this different from LinkedIn or Naukri's tools?
A: LinkedIn and Naukri provide basic skill matching. Our platform provides:
   1. Full resume extraction and parsing
   2. ML-based career prediction with confidence scores
   3. Multi-dimensional ATS scoring
   4. Personalized week-by-week learning roadmaps
   5. AI-generated cover letters
   6. Interactive BI dashboard
   7. Job description matching with cosine similarity
   All in one free, open-source platform.

Q11: How many resumes did you test it on?
A: We tested on 10 diverse real-world sample resumes covering different
   templates: Microsoft Word, Canva, LaTeX/Overleaf, ATS-friendly, and
   plain text. All 10 passed our end-to-end pipeline with 100% success rate.

Q12: What is cosine similarity?
A: A mathematical formula that measures how similar two text documents are.
   Value ranges from 0 (completely different) to 1 (identical).
   We use it in the Job Description Matcher to compare your resume text
   against a target job description and give a match percentage.
