================================================================================
KEY TERMS TO KNOW (In Case Examiner Asks)
================================================================================

TF-IDF:
  Converts words to numbers. Words that appear often in ONE resume but rarely
  in ALL resumes get a HIGH score. Common words like "the", "and" get LOW score.

Decision Tree:
  A flowchart-based ML algorithm. Makes decisions by asking Yes/No questions
  about the data, branching into leaves that represent career categories.

SVM (Support Vector Machine):
  Finds the best mathematical line (hyperplane) that separates different career
  categories in the feature space. Works well for text classification.

KNN (K-Nearest Neighbors):
  Classifies a new resume by finding the K most similar resumes in the training
  set and voting on which career category is most common among them.

Accuracy = (Correct Predictions / Total Predictions) × 100
Precision = True Positives / (True Positives + False Positives)
Recall    = True Positives / (True Positives + False Negatives)
F1-Score  = 2 × (Precision × Recall) / (Precision + Recall)

Confusion Matrix:
  A grid/table where rows = actual career labels, columns = predicted labels.
  The diagonal from top-left to bottom-right should be all HIGH values
  (showing correct predictions). Off-diagonal values are mistakes.

Cross-Validation:
  Instead of testing once, we test 10 different times on different subsets of
  data. Average score across all 10 folds gives a reliable accuracy estimate.

Label Encoding:
  Converting text category names to numbers so ML algorithms can process them.
  Example: "Data Scientist" → 3, "Web Developer" → 22

Pickle (.pkl) file:
  A Python file format that saves a trained object (like an ML model) to disk.
  Joblib.dump() saves it. Joblib.load() loads it back.

Skill Gap Analysis:
  Set difference operation: Required Skills − Candidate Skills = Missing Skills
  Then prioritize missing skills by how important they are for the role.
